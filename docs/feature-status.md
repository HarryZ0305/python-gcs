# Feature status and remaining work

This describes the committed source, not operational flight readiness.
**Implemented** means a code path exists. **Experimental** means implemented with
remaining validation. **Work in progress** includes planned work that is not
implemented yet; it does not imply availability or a committed delivery date.

## Accurate project description

> Customized drone GCS with OpenStreetMap, improved mission planning, and an experimental telemetry-driven 3D attitude viewer; PX4/Gazebo integration and real-aircraft validation are work in progress.

“Live 3D modeling” would overstate the current implementation: the viewer rotates
a drone model using roll, pitch, and yaw. It does not reconstruct terrain or
display a Gazebo world. “Equipped with Gazebo” would overstate packaging: the GCS
targets a separately installed PX4/Gazebo environment.
