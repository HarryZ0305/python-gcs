Capabilities

Everything you need to command your flight.

Designed from the ground up for PX4 drones, combining aerospace-grade instruments with the speed and flexibility of modern software.

🧭

Primary Flight Display (PFD)

Toggle seamlessly between an authentic aviation artificial horizon (pitch ladder, compass tape, airspeed/alt tapes) and an interactive 3D procedural quadcopter model.

🎯

Guided "Fly to Here" Repositioning

Click anywhere on the satellite map to dispatch instantaneous guided reposition setpoints (MAV_CMD_DO_REPOSITION) with target pulse markers and altitude safeguards.

🗺️

Aerial Survey Grid Generator

Automatically plan serpentine lawnmower grid patterns for aerial photogrammetry, surveying, or search & rescue missions with configurable lane spacing and altitude.

📋

6-Point Pre-Flight Health Checklist

Comprehensive pre-arm verification modal auditing telemetry rates, GNSS 3D fix, battery power thresholds, IMU horizon levelness, and autopilot prearm readiness.

🌐

3D KML & GeoJSON Trail Export

Record flight paths and export them with a single click to Google Earth 3D extruded ribbons (.kml) or standard GeoJSON for GIS spatial analysis.

💾

Full MAVLink Parameter Engine

Real-time parameter search, double-click inline value editing with automatic type-checking, and one-click .param backup and restore.

Tested Hardware

Built for Real Airframes & SITL Simulators.

Targeted specifically at the Holybro S500 quadcopter with a Pixhawk 6C flight controller, perfectly matched against PX4 SITL Gazebo simulation.

Airframe Target Holybro S500 / X500 Multirotor
Flight Controller Holybro Pixhawk 6C / 6X
Autopilot Firmware PX4 Autopilot (v1.14+)
MAVLink Port UDP 14540 (API/Offboard)
Simulator Airframe Gazebo Harmonic / SITL gz_x500
Run PX4 SITL Simulator
# In PX4-Autopilot directory:
make px4_sitl gz_x500

# Or run headless in Docker (Windows/Mac/Linux):
docker run --rm -it -p 14540:14540/udp \

Fast Setup

Take off in less than 3 minutes.

Zero complex dependencies. Run the standalone Windows binary directly, or run from Python source.

1

Download or Clone

Grab the standalone PythonGCS.exe bundle, or clone the repository and run pip install -r requirements.txt.

2

Start SITL or FCU

Power up your Pixhawk 6C telemetry radio or launch PX4 SITL Gazebo. The default port is udpin:0.0.0.0:14540.

3

Connect & Fly

Click CONNECT. Telemetry, maps, and instruments will populate within seconds. Run your pre-flight checklist and fly!
