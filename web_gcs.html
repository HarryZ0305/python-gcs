Gazebo / PX4 SITL

Implemented in the desktop GCS. Your Gazebo integration, MAVLink connection, OpenStreetMap, and 3D attitude model remain available together in the desktop app.

  1. Start your existing PX4/Gazebo simulator: 
    cd ~/PX4-Autopilot
make px4_sitl gz_x500
  2. Run python main.py from the GCS repository.
  3. Open Connection… → PX4 SITL / Gazebo (UDP 14540) → Connect.
  4. In Fly, use Attitude → 3D model beside the OpenStreetMap view.

The hosted browser demo uses generated telemetry. It does not launch your locally installed simulator.
